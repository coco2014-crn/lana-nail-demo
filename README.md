# Lana nail — Webサイト営業提案

## 営業前ブラッシュアップ（2026-09-19）

構造・セクション順・イラスト・特徴的な配置を維持して調整しました。
背景をミルキーホワイトへ、Design・Kids・Accessを淡いアイボリー／グレージュへ変更。CTAはモカ色に統一。
主要本文はPC 15px／スマートフォン14px、補足は原則13pxに調整。日本語キャッチの字間は0.035emに抑え、英字ラベルの字間は維持。
About・Menu・Owner・Accessの上下余白をPC 100pxから80pxへ調整（タブレット64px、スマートフォン54px）。
日本語の不要な読点や重複表現を校正。スマートフォンでは一部の強制改行を解除し、自然な折り返しに変更。
変更後の375 / 768 / 1440px表示を再取得・目視確認。全幅で横はみ出し・画像エラー・JSエラーなし。予約案内、ページ内リンク、reduced-motionも再確認済み。
正式な予約先や料金等の未確認情報は追加していません。公開・アップロードは行っていません。

ローカル専用の1ページ提案サイトです。公開・アップロード・店舗への連絡は行っていません。

## 閲覧

`node server.cjs` をこのフォルダで実行し、http://127.0.0.1:4173 を開いてください。
`dist/index.html` を直接ブラウザで開くこともできます。ローカルURLは相手に送っても閲覧できません。共有用プレビューの作成は別途許可を得て行います。

## ファイル

- `dist/index.html`: 全10セクション、本文、メタ情報
- `dist/styles.css`: レスポンシブデザイン、フォーカス表示、動きの軽減
- `dist/site.js`: 予約先設定と未設定時の案内
- `dist/assets/hero.svg`, `design-1.svg`〜`design-3.svg`: この提案用に作成したオリジナルイラスト
- `server.cjs`: 外部ライブラリ不要、ループバック限定のローカルサーバー
- `make-assets.cjs`: イラスト再生成用
- `check.cjs`: この環境のPlaywrightとEdgeを使った表示確認
- `qa/`: 確認結果JSONと各幅の全ページ画像（Git対象外）

## 情報の扱い

作業開始時点では `.git` 以外の既存ファイル・資料はありませんでした。
店舗の情報源は今回のユーザー提供指示書のみです。外部情報による独立検証は行っていません。

指示書に記載された店名、福岡市早良区小田部、1席、子連れOK、駐車場1台、フィルイン対応、シンプル・ニュアンス系、元保育士という特徴のみを使用しています。
詳細住所・営業時間・料金・氏名・資格・口コミ・電話番号・予約URLは作成していません。
イラストは実際の施術、店舗設備、提供可能メニューを示すものではありません。掲載箇所にイメージ表記を付けています。

## 差し替え

1. 正式な予約URLを確認後、`dist/site.js` の `salonLinks.reservation` にHTTPS URLを設定。
2. Instagramは設定枠のみで画面には未掲載。アカウントを確認後、実際のリンク要素とともに追加。
3. 許諾済みの施術写真を用意し、HTML内の画像パス・alt・寸法を更新。画像の比率はCSSで統一。
4. Menuに正式メニュー・料金・オフ料金等を追加。
5. Ownerの提案用文章を、承認済みプロフィール・メッセージへ差し替え。
6. Accessに公開可能な住所・営業時間・アクセス情報を追加。地図は実地点確認後に設定。
7. 正式公開時のみ、提案バナー・提案注記・title・descriptionを見直し、`noindex, nofollow` を変更。OGP画像、絶対URL、canonicalは公開先確定後に設定。

## 確認結果

Edgeによる375 / 768 / 1440px幅の確認：横はみ出しなし、全画像正常、h1は1つ、ページ内リンクの参照先正常、JS・HTTPエラーなし。
予約未設定時の案内表示、reduced-motion有効時のスムーズスクロール停止を確認。
375 / 1440pxの全ページキャプチャを目視確認。768pxも取得済み。
HTMLにはlang、viewport、title、description、alt、セマンティックな見出し、スキップリンク、focus-visible、予約案内のlive statusを実装。
noindexは検索掲載を抑える指定でありアクセス制限ではありません。現状は127.0.0.1のみで配信しています。
